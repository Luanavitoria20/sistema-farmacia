# 💊 Sistema Farmácia

Um projeto de desenvolvimento de software para gerenciamento de uma farmácia, criado com o objetivo de praticar e aprimorar conhecimentos em programação e desenvolvimento web.

## 📌 Sobre o projeto

O **Sistema Farmácia** é um projeto desenvolvido para organizar e facilitar a gestão de informações relacionadas a uma farmácia.

O projeto está em desenvolvimento e busca aplicar conceitos de frontend, backend e integração entre sistemas.

## 🎯 Objetivos

- Desenvolver um sistema para o contexto de uma farmácia.
- Praticar programação e organização de código.
- Aprimorar conhecimentos em desenvolvimento web.
- Aprender a trabalhar com Git e GitHub.

## 🛠️ Tecnologias

- **Frontend:** interface da aplicação.
- **Backend:** NestJS.
- **Versionamento:** Git e GitHub.

*Observação: as tecnologias e funcionalidades devem ser atualizadas conforme a implementação atual do projeto.*

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Luanavitoria20/sistema-farmacia.git
```

### 2. Acesse a pasta do projeto

```bash
cd sistema-farmacia
```

### 3. Instale as dependências

Entre na pasta do backend e instale as dependências:

```bash
cd backend
npm install
```

### 4. Execute o backend

```bash
npm run start:dev
```

### 5. Execute o frontend

Abra a pasta `frontend` no Visual Studio Code e execute a aplicação conforme a configuração do projeto.

> **Importante:** os comandos de execução dependem dos arquivos de configuração existentes em cada pasta.
